# 👗 Veruska

Website for **Veruska**, a textile art and fashion brand from Argentina. Built for a real client, it presents the brand, its collaborations and its product catalog.

🔗 **Live site:** [veruska.vercel.app](https://veruska.vercel.app)

## ✨ Features

- Product catalog with **category filters** (dresses, blouses, trousers, aprons)
- Product detail view and a dedicated mobile layout
- Pages for Home, About us, Clients, Products and Contact
- FAQ about purchases, shipping and returns (accordion)
- Clients carousel with **Swiper**
- Responsive design with **Tailwind CSS**, client-side routing with React Router

## 🛠️ Tech stack

React · Vite · Tailwind CSS · React Router · Semantic UI · Swiper · ESLint · Prettier

## 🚀 Run locally

```bash
git clone https://github.com/leandrobattocchio/veruska.git
cd veruska
npm install
npm run dev
```
